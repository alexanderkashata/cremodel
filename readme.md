## 📌 Overview

**CREModel** is a Python-based tool for evaluating commercial real estate investments. Built with **Streamlit**, the app provides an interactive way to analyze annual property cash flows, debt amortization, and flexible exit strategies.

This tool helps investors and analysts understand key investment metrics such as IRR, equity multiple, cap rate, and debt service coverage. The model supports a user-defined exit year (between 5–10 years) and handles loan amortization over the holding period.

---

## 🧮 Features

- 📈 **Annual Cash Flow Modeling**  
  Simulates net operating income and debt payments over time.

- 💸 **Loan Amortization**  
  Calculates principal and interest payments for fixed-rate loans.

- 🔁 **Exit Strategy Analysis**  
  Allows users to select an exit year and input a cap rate to estimate sale proceeds and equity returns.

- 📊 **Return Metrics**  
  - Internal Rate of Return (IRR)  
  - Equity Multiple  
  - Cap Rate  
  - Cash-on-Cash Return
